Prototype de mesure relative avec la caméra du téléphone.

PRINCIPE

Choisis une zone comme référence 0,0 stop, puis pointe le téléphone vers une autre zone. Le prototype mesure seulement l'écart relatif — jamais une exposition « correcte ».

BÊTA · Ne pas utiliser comme posemètre absolu. Le but du test est d'abord de vérifier la répétabilité du téléphone.

      PROTOCOLE DE TEST CONSEILLÉ
      
    
        
  1. Déploie le prototype en HTTPS et ouvre-le sur le téléphone.
    2. 
        
  2. Pointe une surface uniforme, attends environ 1 seconde, puis fais DÉFINIR COMME RÉF.
    3. 
        
  3. Le prototype choisit automatiquement LOCK si le verrouillage est fiable, sinon AUTO-METER si ISO + temps d'exposition sont lisibles.
    4. 
        
  4. Sans changer de caméra du téléphone, pointe une seconde zone et note l'écart.
    5. 
        
  5. Pour vérifier la précision, mesure idéalement la même surface sous deux niveaux de lumière connus, ou compare avec une cellule / une caméra de référence.
    6. 
        
  6. Refais la mesure plusieurs fois : la répétabilité est plus importante que d'obtenir immédiatement le « bon » chiffre.
